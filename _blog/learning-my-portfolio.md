This website is more than a portfolio — it is a learning project built on GitHub Pages. I wanted to practice publishing a site with GitHub, using Markdown, and learning how a Jekyll-powered page works.

As a 3D artist and generalist, I often focus on modeling, texturing, and asset production. Making this portfolio gave me a chance to also learn how to present my work online, manage a repository, and make my site easier to update.

## What I learned

- How to create and edit pages with Markdown
- How GitHub Pages serves a website directly from a repository
- How layout templates and includes keep the site consistent
- How navigation and permalinks work in a Jekyll site

## Why I built this

I built this page to document my learning process and to make it easier for others to see both my projects and the steps I am taking to improve my skills. This portfolio is a work in progress, and I will continue refining it as I learn more.
